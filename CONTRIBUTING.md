# Внесок у Prompt Saver

1. Створіть окрему гілку для однієї зміни.
2. Зберігайте всі написи інтерфейсу українською.
3. Не додавайте ключі, бази SQLite, папку `data` або збірки до Git.
4. Для кожної зміни поведінки оновіть [CHANGELOG.md](CHANGELOG.md) згідно з [RELEASE_CHECKLIST.md](RELEASE_CHECKLIST.md).
5. Перед pull request виконайте `npm run lint`, `npm test` і `npm run build`.
6. Опишіть у PR поведінку зміни та спосіб її перевірки.
