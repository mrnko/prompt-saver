# Security policy

## Повідомлення про вразливість

Не публікуйте ключі OpenAI, персональні промпти чи деталі вразливостей у GitHub Issues. Створіть приватне повідомлення власнику репозиторію з описом, кроками відтворення та оцінкою впливу.

## Секрети

Prompt Saver ніколи не зберігає OpenAI API key у репозиторії, SQLite або конфігураційному файлі. На Windows ключ розміщується у Credential Manager поточного користувача.
