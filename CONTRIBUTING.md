# Внесок у Prompt Saver

1. Створіть окрему гілку для однієї зміни.
2. Зберігайте всі написи інтерфейсу українською.
3. Не додавайте ключі, бази SQLite, папку `data` або збірки до Git.
4. Перед pull request виконайте `npm run lint`, `npm test` і `npm run build`.
5. Опишіть у PR поведінку зміни та спосіб її перевірки.
